# Lessons Learned: Automating Security & Operations with Python, Flask, Docker, and Ansible

Overview: combine GitHub REST API automation, Flask/Jinja app with regex validation and logging, and Docker container orchestrated via Ansible.

Key takeaways:
- Status-aware API calls; never hardcode tokens.
- Jinja templates for dynamic forms; regex for email/phone; structured logs.
- Dockerfile on python:3.13; Ansible Docker modules to build/run; expose port 5000.

Troubleshooting: check token scopes, regex anchors, container logs, and Ansible module availability.
